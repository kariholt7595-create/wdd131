Points Playground Site Plan

Site Name

Points Playground

As kids we loved the playground. But now we are adults and we still want to have the fun we had as kids. This name is my take on bringing the childhood fun of the playground into the fun world of earning points for grown-up fun. For me, that is traveling and I use credit card points to make that happen. So, Points Playground is a fun name that captures the essence of what I want this site to be about.

Site Purpose

The purpose of this website is to provide information for earning reward points and using them for travel. I have learned some about this and want to share that it is possible to take amazing trips by using points. I also want to help people realize that it isn't always best to just use a credit card portal for booking things. It will also point people to other resources that can learn more in depth about using points for travel.

Scenarios

  • How can I start earning reward points?
  • Can I use points to book flights?
